# 대학도시 천안 — 인터랙티브 웹 프레젠테이션

원본 PPTX 6장의 이미지와 내용을 유지한 정적 웹 프레젠테이션입니다. 서버/DB/빌드 도구/외부 CDN이 필요 없습니다.

## 실행
- `index.html` 파일을 브라우저에서 열면 바로 실행됩니다.
- 웹 게시 시 **index.html, styles.css, script.js, assets 폴더 전체**를 같은 디렉터리에 업로드하세요.

## GitHub Pages 게시
1. GitHub에서 새 저장소를 생성합니다.
2. 압축파일을 풀어 나온 `index.html`, `styles.css`, `script.js`, `assets/`를 저장소 루트에 업로드합니다. 압축파일 자체를 업로드하지 마세요.
3. **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch를 `main`, Folder를 `/(root)`로 지정하고 저장합니다.
5. 게시 주소: `https://<사용자명>.github.io/<저장소명>/`

## 조작
- 화면 상단 목차, 하단 이전/다음, 점 네비게이션, 슬라이드 전체 보기
- 키보드 ←/→, PageUp/PageDown, Home/End, Space
- PC 마우스 휠, 모바일 좌우 스와이프
- 카드 클릭 시 관련 설명 팝업(2~5번 슬라이드)
- 발표 참고사항, 확대, 자동 재생(5.5초 간격), 전체 화면
- `#slide-3`처럼 URL 해시로 개별 슬라이드 바로가기

## 참고
- 이미지는 원본 PPTX를 직접 렌더링한 것입니다. 원본 디자인과 텍스트 누락을 방지하기 위해 슬라이드 전체를 이미지로 보존하고 상호작용은 HTML로 덧붙였습니다. 따라서 슬라이드 안의 글자는 HTML 텍스트로 직접 편집할 수 없습니다.
- 보조 팝업과 발표 참고사항은 PPTX의 원문 내용 및 발표자 노트를 바탕으로 구성했습니다.
- 원본에서 사용된 콘셉트 일러스트 속 대학 로고와 천안시 심벌의 공식 사용 적합성, 대학 캠퍼스 소재지, 명칭은 대외 공개 전에 확인해야 합니다.
